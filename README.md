# 🏋️‍♂️ VibeFit — Gym Management System  
**Live Demo:** https://vibe-fit-pd6a.vercel.app/  
**Repository:** https://github.com/odongograce/VibeFit  

A modern gym management web application with user authentication, personalized dashboards, dynamic workout plans, and service listings — built with **React**, **Bootstrap**, and **JSON Server**.

---

## 🚀 Tech Stack
- **React.js**
- **JavaScript (ES6+)**
- **Bootstrap**
- **React Router**
- **JSON Server (Mock API)**
- **CSS & Responsive UI Design**

---

## ⭐ Key Features

### 🔐 **User Authentication**
- Users can register and log in securely  
- Each user receives a dynamic dashboard after login  

### 🧭 **Dynamic Routing**
- Personalized dashboards using React Router  
- Clean navigation structure  

### 💪 **Mood-Based Workout Generator**
- Users select their mood  
- System generates a custom workout plan dynamically  

### 🏡 **Landing Page**
Includes:
- About Us  
- Contact  
- Gym Services  

### 🧘 **Gym Services & Shop**
- Aerobics  
- Yoga  
- Gym accessories (gloves, straps, etc.)

### 🔁 **CRUD Functionality (Admin-like features)**
- Manage memberships  
- Update dashboard content via JSON Server

### 1️⃣ Clone the repository
```bash
git clone https://github.com/odongograce/VibeFit.git
 

2️⃣ Navigate into the project
cd VibeFit

3️⃣ Install dependencies
npm install

4️⃣ Start the development server

5️⃣ Start JSON Server (if included)
