# 🏋️‍♂️ VibeFit Gym Management System

**Tech Stack:** React, JavaScript, Bootstrap, JSON Server

A responsive web application for gym management with user authentication, dynamic dashboards, and personalized workout plans.

---

## 🔹 Features
- **User Authentication:** Register and log in securely  
- **Dynamic Routing:** Each user has a personalized dashboard  
- **Personalized Workouts:** Users select their mood and the system generates custom workout plans  
- **Landing Page:** About Us, Contact, and Services sections  
- **Gym Services:** Aerobics, Yoga, and equipment purchases like gloves, straps  
- **Full CRUD Functionality:** Manage gym members and plans via JSON Server

## 💻 How to Run Locally
1. Clone the repository:  
```bash
git clone https://github.com/odongograce/VibeFit.git


2. Navigate to the project folder:
cd VibeFit  

3. Install dependencies:
npm install

4. Start the development server:
npm start

5. Open http://localhost:3000 in your browser
